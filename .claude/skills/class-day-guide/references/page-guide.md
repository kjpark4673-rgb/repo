# 학생 가이드 페이지와 빌더

## 빌더 쓰는 법

Day 17부터는 공통 부분을 `classroom/tools/guide_common.py`로 떼어 썼다(`from guide_common import *` 뒤 `PR`, `body`를 만들고 `build_page(제목, body, 처음값, 'l17-')` → `write_page`). 새 날짜는 `build_day17.py`나 `build_day18.py`를 복사하는 편이 짧다. `build_day16.py`는 발행된 Day 16 가이드를 글자 하나 다르지 않게 다시 만드는 기준으로 그대로 둔다.

1. `cp classroom/tools/build_day16.py classroom/tools/build_dayNN.py` 후 맨 위 설명, `PATH`(출력 파일), 제목(`<title>`)을 바꾼다.
2. 바탕(스타일과 스크립트)은 `classroom/tools/guide_base.html`에서 읽는다. 하루 지도, 카드 같은 덧붙인 스타일은 `EXTRA_CSS`.
3. 프롬프트는 `PR['p00']`처럼 사전에 넣는다. 본문은 `body` 문자열 한 덩어리다.
4. `python3 classroom/tools/build_dayNN.py [출력 경로]`. 경로를 주면 시험용 사본을 만든다.

| 도우미 | 하는 일 |
|---|---|
| `tok(key, 처음값)` | 프롬프트 안의 파란 글자 `<b data-v="key">`. 같은 key의 입력 칸에 적으면 바뀐다 |
| `field(key, 설명, '비워 두면: 처음값')` | 한 줄 입력 칸 |
| `fieldwide(key, 설명, '비워 두면: 처음값')` | 여러 줄 입력 칸(붙여 넣기용). 줄바꿈은 프롬프트에서 띄어쓰기가 된다 |
| `box(id, 제목, 글)` | 눌러서 복사하는 상자. id는 영문 소문자와 숫자(p02b처럼). runchain.py가 이 id로 프롬프트를 뽑는다 |
| `pick_card(...)`, `data-pick` | 보기 카드의 "이걸로 할게요"가 입력 칸을 채운다 |
| `expand_mvp_plain`, `expand_mvp_html` | MVP를 "MVP(Minimum Viable Product)"로(프롬프트는 줄마다 처음, 본문은 문단마다 처음) |
| `DEF` (스크립트 안) | 입력 칸이 비었을 때 들어갈 처음 값. **새 key를 만들면 여기에도 넣는다** |
| 갤러리 | 시험 화면을 `node classroom/tools/shot_screen.js 화면.html 출력.jpg`로 찍어 `day16_gallery`처럼 폴더에 두고 `SHOTS`에 적는다 |

## 페이지 규칙 (강사 지시로 정한 것)

- 아티팩트 이름은 "Day N · 주제"(주제는 그날의 핵심 개념). 머리말은 "Day N / 52 · 11/16(월)".
- 맨 앞은 하루 지도: 덩어리 세 개 안팎과 시간표, 줄마다 "남는 것". 줄을 누르면 그 구간으로 간다. 맨 앞 구간의 보이는 설명 글은 800자 안팎.
- 구간 머리: "덩어리 · 시간 · 교시" / 제목 / "왜 해요?" 한 줄. 교시마다 "이 ○가지가 되면 성공" 체크, "먼저 끝났다면".
- 준비 구간: 프롬프트 쓰는 법, 허락 창(그 프롬프트가 실제로 부르는 명령 이름까지), 입력 칸, P0, W1, 리모컨(지금 보내는 상자가 아니라고 적는다).
- 맨 끝: 막히면(증상 → 한 줄). 한 줄도 될 수 있으면 돌려 본다.
- "페이지"라고만 쓰지 않는다(랜딩페이지, 상세페이지, 웹페이지). 새 개념은 처음 나오는 자리에서 뜻, 그것인 것과 아닌 것, 비유를 쓴다. "오늘 처음 나오는 말" 카드에 모은다.
- 강사의 현업 이야기는 "현업 이야기 · 강사님" 카드에 강사가 한 말만. 학생의 속마음을 따옴표로 인용하지 않는다.
- 입력 칸은 비워 두고 처음 값은 흐린 글씨("비워 두면: 아직 모름").
- 학생 자료에서는 Claude Code의 내부 도구 이름 대신 학생이 보는 말(허락 창, 옆 창, 대화 목록)을 쓴다.

## 다른 대화에서 발행한 날짜를 고칠 때

- 링크를 지키려면 `url`을 넣어 발행한다. 이 대화에서 아직 보지 않은 아티팩트면 거절되면서 발행본과의 줄 차이가 나오고, 그것으로 "본 것"이 된다. 큰 페이지(이미지가 든 가이드)도 발행본 전체를 읽을 필요가 없다.
- 차이에 내가 고친 줄만 있으면(다른 사람이 고친 줄이 없으면) 같은 파일을 다시 보낸다. 한 번 더 거절되면 한 번 더 보내면 올라간다. 차이에 내가 모르는 줄이 있으면 그 줄을 내 파일에 옮겨 담고 보낸다.
- 공유 설정("링크가 있는 사람")은 다시 올려도 그대로다.
