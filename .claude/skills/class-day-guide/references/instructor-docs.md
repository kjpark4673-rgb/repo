# 강사 문서 틀

모두 `classroom/` 아래에 있고 학생에게 주지 않는다. 공개 저장소라 학생 이름과 학생별 내용은 적지 않는다.

## 시연카드 `classroom/instructor/dayNN-시연카드.md`

1. 맨 위: 학생용 가이드 링크와 아티팩트 이름, 다른 강사 문서 위치.
2. 이번 판에서 바뀐 것: 강사 지시(말 그대로) → 문답으로 정한 것 → 오전 기초 / 오후 심화 / 빠진 것 / 내 결정.
3. 시작 전에(5분): 공유 상태 확인, 새 대화에서 시작, 첫 줄("작업이 끝날 때마다 커밋하고 푸시해 줘. 커밋 안내 문장은 쓰지 마. 답은 항상 한국어로"), 시연할 입력 값.
4. 하루 순서 표: 시간 / 강사 / 학생.
5. 1교시를 시작할 때 말할 것, 현업 이야기를 꺼내는 순간(구간과 대본 위치).
6. 프롬프트별 걸리는 시간 표: 시험 평균과 범위, 수업에서 생길 일.
7. 웹에 기대는 단계를 수업 중에 살피는 표: 물을 것 / 이렇게 나오면 / 그 자리에서 할 일.
8. 전날 10분만 눌러 볼 화면(이 환경에서 못 돌린 것만).
9. 학생이 막힐 때 한마디 표: 증상 / 한마디.

## 모의수업 `classroom/instructor/dayNN-모의수업.md`

1. 시트에서 본 반의 모습(묶음 숫자 표, `student-status.md`의 틀).
2. 가상 학생으로 돌린 결과 요약.
3. 시간대별 예상 대화 표: 시간 / 학생이 할 말 / 답 한 줄 / 가이드에서 볼 곳.
4. 수강생 눈 검토 표: 걸린 것 / 학생 입장에서 생기는 일 / 고친 것. 고치지 않은 것과 이유.

## 시험 결과 `classroom/tests/dayNN-test-results.md`

맨 위에 판마다 절을 새로 둔다(가장 최신을 위로). 절마다: 강사 지시 한 줄 / 모두 몇 회, 끝까지 돌았는지, 사용량 / 문구를 고친 곳 / 발행 상자가 어느 시험본과 같은지 / 차례별 갈래 표(입력한 것, 돌린 순서, 나온 것) / 프롬프트별 걸린 시간 / 문구를 고치게 만든 실패 / 이 환경에서 생긴 일 / 이 시험이 보장하지 않는 것.

## 인수인계 `HANDOFF.md`

- 새 7-xx 절을 "## 8. 새 세션 첫 메시지" 바로 위에 넣고, 그 전 절 제목에서 "— 가장 최신"을 뗀다. 맨 위 "새 세션은 … 순서로 먼저 읽습니다"와 마지막으로 고친 날을 고친다.
- 절의 틀: 강사 지시(말 그대로, 거친 말은 옮기지 않음) / 문답으로 정한 것 / 구조 / 시험 / 수강생 눈 검토 / 발행 링크 / 강사 문서 / 아직 강사 답이 없는 것.
- 강사가 모든 수업에 적용하라고 한 규칙은 0번에 한 줄로 더한다(지시한 날짜와 말을 괄호로).

## 용어 사전 `classroom/tools/build_glossary.py`

DAYS에 그날 이름을 맞추고, 그날 나온 말의 "수업에서" 줄을 고치거나 새 말을 add()로 더한다. `python3 classroom/tools/build_glossary.py` 후 같은 링크로 발행한다. "수업에서" 줄은 공식 일정표와 가이드에 적힌 것만 쓴다.
