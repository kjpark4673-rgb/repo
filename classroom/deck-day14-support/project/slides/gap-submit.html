학생이 자주 묻는 것

  • HTML은 링크가 없는데요?
  • 몇 개 내야 해요?
  • 파일 이름은요?
  • 미완성이면요?

미리 정할 것

  • 제출 방법 (구글 드라이브 폴더 등)
  • 최소 개수와 파일 이름 규칙
  • 미완성도 제출 (진행 상태 표기)
  • 평가 기준 공개

Day 14 보강 해설 · 교안 진단

HTML 파일은 웹 주소가 없어서 시트에 링크로 붙일 수 없습니다. 오늘은 구글 드라이브 공유 폴더에 파일을 올리고 그 폴더 링크를 시트에 붙이는 방식이 가장 간단합니다. 웹 주소 배포는 금요일 Netlify 시간에 합니다. 구체적인 규칙과 평가 기준은 운영 파트에 있습니다.
