# 학생 작업 폴더에 넣는 것 (student-kit)

> 강사용 설명이에요. 이 폴더의 파일은 학생 가이드의 상자가 그대로 실어서 학생 작업 폴더에 저장하게 하는 원본이에요.

## design-first (설계 먼저)

- `design-first/SKILL.md` 하나가 원본이에요. 11/24(Day 22) 2교시 "설계 먼저 스킬 설치" 상자가 이 글을 한 글자도 바꾸지 않고 학생 작업 폴더의 `.claude/skills/design-first/SKILL.md`로 저장하게 해요. Day 23·24 가이드에도 같은 설치 상자가 있어요(안 한 학생용).
- 빌더는 `classroom/tools/guide_common.py`가 이 파일을 읽어 설치 상자(`DFI`)를 만들어요. 그래서 **이 파일을 고치면 세 가이드의 설치 상자가 모두 바뀌어요.**
- 비유: 가게 공사예요. 벽부터 두드려 벽 속 수도관을 찾고(현장 조사) → 도면에 주인의 빨간펜을 받고(설계서 승인) → 도면대로만 지어요(제작). 단계마다 Claude가 멈추고 사람의 말을 기다려요.
- 부르는 법: 한국어 한 줄 "설계 먼저 해줘: ○○"(권해요) 또는 `/design-first ○○`. 둘 다 돌려 봤어요(`classroom/tests/design-first-test-results.md`).

### 고칠 때 지킬 것

1. **11/24 수업 뒤에는 되도록 고치지 않아요.** 학생 28명의 작업 폴더에 이미 같은 글이 들어가 있어요. 꼭 고쳐야 하면 설치 상자가 "다른 글이 있으면 SKILL_v번호.md로 남긴 뒤 새로 저장"하니, 다음 날 가이드에서 설치 상자를 한 번 더 보내게 안내해요.
2. **머리말의 `description:` 값은 작은따옴표로 통째로 감싼 채로 둬요.** 큰따옴표로 시작하고 뒤에 글이 이어지면 Claude가 설명을 읽지 못해 한국어 한 줄로 불리지 않아요(11/24 새벽에 확인).
3. 고친 뒤에는 Day 22·23·24 가이드를 다시 빌드하고, 설치 → 조사 → 설계서 → 승인을 직무 네 가지 이상으로 다시 돌린 뒤 올려요(`.claude/skills/class-day-guide/references/testing.md`의 "설계 먼저 상자 시험").

### 12/2 "내 AI 팀 키트" 때 할 것 (강사 결정, 11/23)

작업 폴더의 스킬을 모든 프로젝트에서 쓰도록 개인 스킬 폴더로 복사하는 상자를 넣어요. 맥·리눅스 기준 `mkdir -p ~/.claude/skills && cp -r .claude/skills/design-first ~/.claude/skills/`예요. 윈도우는 수업 전에 돌려 봐야 해요(공식 문서에 윈도우 경로가 적혀 있지 않아요). 작업 폴더 밖을 고치는 일이라 허락 창이 떠요. 같은 이름의 스킬이 두 곳에 있으면 개인 폴더 것이 먼저 쓰여요.
