# Day 16 강사 시연 카드 (11/16 월, 가이드 3판 기준)

> 학생용 자료가 아닙니다. 금요일 시연이 멈춘 원인 가운데 강사 화면 쪽 원인을 미리 없애는 순서입니다.
> 학생용 가이드: https://claude.ai/artifact/Jd3TjZhwSwPpdmJRTUhj8R (비공개 상태. 수업 전에 공유 설정을 바꿔야 학생이 열 수 있습니다)
> 예상 질문과 답은 `day16-모의수업.md`에 있습니다.

## 시작 전에 (5분)

1. **가이드 공유 설정을 "링크가 있는 사람"으로 바꿉니다.** 금요일 가이드 맨 위에는 "새 가이드 링크는 월요일 수업을 시작할 때 드려요"라고 적어 두었습니다.
2. **새 대화에서 시작합니다.** 지난주 대화를 이어 쓰면 대화가 압축되면서 답이 느려지고 영어로 바뀌는 일이 있었습니다.
3. 첫 줄로 이것을 보냅니다.
   ```
   오늘 수업 시연 중에는 작업이 끝날 때마다 바로 커밋하고 푸시해 줘. 커밋 안내 문장은 쓰지 마. 답은 항상 한국어로 해 줘.
   ```
   금요일에는 저장소 규칙("커밋은 내가 말할 때만")과 종료 훅("커밋하라")이 부딪혀 답마다 커밋 안내가 붙었습니다. 이 한 줄로 실제로 사라지는지는 강사 저장소에서 시험하지 못했습니다.
4. 가이드의 **P0**을 보냅니다. 금요일에 들어간 "멈추고 묻기", "아카이브에 없는 광고 인용 금지" 두 줄을 지우고 오늘 규칙을 넣습니다. 다른 줄은 건드리지 않습니다(시험에서 확인).

## 3판에서 달라진 것

- **프롬프트에 채울 괄호가 없습니다.** 학생이 적을 값(이미 정한 브랜드, 계획에서 바꿀 것, 브랜드 색, 테크 트랙의 도구)은 페이지의 입력 칸에 적습니다. 아무것도 적지 않고 붙여도 "없음"으로 나가서 그대로 돌아갑니다.
- P1의 "이미 정한 브랜드" 칸에 세 곳을 적으면 그 세 곳으로 벤치마킹이 나옵니다(시험에서 확인).
- 꼭 하는 프롬프트 제목에 (꼭)이 붙어 있습니다: P0, P1, P3, P5, P6, P10. 테크 트랙은 P0, P1, T1, T2, T3.
- 첫 화면을 장면으로 다시 만드는 P7이 3교시에서 4교시로 갔습니다.
- 테크 트랙도 계획부터 받고(T2) 만들며(T3), 4교시에 다듬고(T4), 오후에 샘플 데이터를 붙입니다(T5).
- 리모컨이 일곱 개입니다. "파일 내용 보기"(글 파일을 화면에 보여 줌)와 "광고 규정 점검"(위험한 표현 5개를 표로 보여 주고 고침)이 새로 들어갔습니다.
- 마무리에 "화면을 링크로 만들기"와 선택 구간 P12(오늘 한 일을 스킬로 묶기)가 있습니다.

## 전날 10분만 눌러 볼 화면

아래는 화면을 직접 눌러 볼 수 없어서 공식 문서로만 확인했습니다.

| 화면 | 공식 문서에 적힌 것 | 안 되면 |
|---|---|---|
| 계획 모드 | 입력창 아래의 모드 선택에서 Plan을 고른다. 클라우드 세션의 모드는 Accept edits / Plan / Auto. 계획이 뜨면 승인하고, 승인하면 만들기 시작한다 | P5와 P6이 같은 흐름이다. 학생에게는 "강사 화면으로만 보고 누르지 않는다"고 적어 두었다 |
| Claude Design | 오른쪽 위 Export → Handoff to Claude Code → "Send to local coding agent" 또는 "Send to Claude Code Web". Claude Code 쪽 명령은 /design. Pro에 포함되고, 사용량은 Claude와 같은 한도에서 빠진다 | 가이드의 선택 구간을 건너뛴다 |
| 화면을 링크로 만들기 | Claude Code에서 아티팩트 발행은 Pro에서 된다. 앱과 Claude Code 버전 조건이 있다 | 마무리에서 "드라이브에 올리고 그 링크를 적는다"로 안내한다 |

- 계획 모드를 켠 채로 P5를 넣으면 꼬입니다. 계획 모드를 보여 줄 때는 P6만 넣습니다.
- 스니핏 연결은 금요일에 끝나지 않았습니다. 강사 앱의 설정 → 커넥터에서 직접 추가하고 스니핏 계정으로 로그인해야 합니다. 오늘 본선은 스니핏 없이 돌아갑니다.
