# Day 16 강사 시연 카드 (11/16 월)

> 학생용 자료가 아닙니다. 금요일 시연이 멈춘 원인 가운데 강사 화면 쪽 원인을 미리 없애는 순서입니다.
> 학생용 가이드: https://claude.ai/artifact/Jd3TjZhwSwPpdmJRTUhj8R (비공개 상태. 공유는 강사가 직접)

## 시작 전에 (5분)

1. **새 대화에서 시작합니다.** 지난주 대화를 이어 쓰면 대화가 압축되면서 답이 느려지고 영어로 바뀌는 일이 있었습니다.
2. 첫 줄로 이것을 보냅니다.
   ```
   오늘 수업 시연 중에는 작업이 끝날 때마다 바로 커밋하고 푸시해 줘. 커밋 안내 문장은 쓰지 마. 답은 항상 한국어로 해 줘.
   ```
   금요일에는 저장소 규칙("커밋은 내가 말할 때만")과 종료 훅("커밋하라")이 부딪혀 답마다 커밋 안내가 붙었습니다. 이 한 줄로 실제로 사라지는지는 강사 저장소에서 시험하지 못했습니다.
3. 가이드의 **P0**을 보냅니다. 금요일에 들어간 "멈추고 묻기", "아카이브에 없는 광고 인용 금지" 두 줄을 지우고 오늘 규칙을 넣습니다. 다른 줄은 건드리지 않습니다(시험에서 확인).

## 본선 다섯 개와 걸리는 시간

시험에서 잰 시간입니다. 학생 화면에서는 허락 창을 누르는 시간이 더 붙습니다.

| 순서 | 프롬프트 | 남는 파일 | 걸린 시간 |
|---|---|---|---|
| 1 | P1 벤치마킹 한 장 | benchmark.md | 약 1분 (웹 검색) |
| 2 | P3 MVP 정의서 | mvp.md | 약 30초 |
| 3 | P5 계획부터 받기 | plan.md | 약 25초 |
| 4 | P6 계획대로 만들기 | landing.html | 약 40초 |
| 5 | P10 키비주얼과 SNS 시안 프롬프트 | kv.md | 약 35초 |

나머지(P2, P4, P7, P8, P9, P11)는 15초~1분입니다. 열두 개를 다 넣어도 기다리는 시간은 7분 안팎입니다.

## 결과를 화면에 띄우기

- 클라우드 세션에서는 "landing.html을 아티팩트로 보여 줘"라고 하면 링크가 생깁니다. 이 저장소의 작업 세션에서 가이드를 발행해 온 방식과 같습니다.
- 학생 화면(데스크톱 앱에서 내 컴퓨터 폴더를 연 경우)에서는 답에 나온 파일 이름을 누르면 옆 창에 열립니다(공식 문서 기준).

## 전날 10분만 눌러 볼 화면

아래 셋은 화면을 직접 눌러 볼 수 없어서 공식 문서로만 확인했습니다.

| 화면 | 공식 문서에 적힌 것 | 안 되면 |
|---|---|---|
| 계획 모드 | 입력창 아래의 모드 선택에서 Plan을 고른다. 클라우드 세션의 모드는 Accept edits / Plan / Auto. 계획이 뜨면 승인하고, 승인하면 만들기 시작한다 | P5와 P6 두 줄이 같은 흐름이다 |
| Claude Design | 오른쪽 위 Export → Handoff to Claude Code → "Send to local coding agent" 또는 "Send to Claude Code Web". Claude Code 쪽 명령은 /design. Pro에 포함되고, 사용량은 Claude와 같은 한도에서 빠진다 | 선택 구간을 건너뛰고 P5로 간다 |
| 공개 디자인 스킬 | P8이 공개 주소에서 SKILL.md를 내려받아 .claude/skills/frontend-design/에 저장한다. 시험에서는 원본과 똑같이 저장됐다 | P9는 스킬 파일이 없어도 돌아간다 |

- 계획 모드를 켠 채로 P5를 넣으면 꼬입니다. 계획 모드를 보여 줄 때는 P6만 넣습니다.
- 스니핏 연결은 금요일에 끝나지 않았습니다. 강사 앱의 설정 → 커넥터에서 직접 추가하고 스니핏 계정으로 로그인해야 합니다. 오늘 본선은 스니핏 없이 돌아갑니다.
