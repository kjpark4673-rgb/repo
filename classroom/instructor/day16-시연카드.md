## 6판에서 바뀐 것 (11/15, 강사님 지시)

**11/15 밤 추가 지시 세 가지:** ① 광고 붙여넣기를 오전 기본으로(2교시 P2-1, 광고 소재면 꼭) ② 테크 카드 추가(일곱째 보기 "경쟁 서비스 기능 조사") ③ 준비 구간의 "Claude가 금요일처럼 멈추지 않게 규칙을 먼저 심어요" 문장을 뺌.

**지시:** "실습이 너무 복잡하고 여러 개다. 기초는 오전에, 어렵고 복잡한 심화는 오후에 학생들이 알아서 하게 해라. 마케터는 광고 시안 리서치, MD·온라인 영업은 경쟁사 가격 조사, 증정품 구성 프로모션 조사, 상세페이지 조사를 매일 했다. 그 노가다 업무를 AI 에이전트로 자동화하거나 고도화해서 불편을 줄이는 데 초점을 맞춰라. 스니핏처럼 업무를 간편하게 하는 MVP를 만들게 해라. 학생에게 보기를 주고, 현업에 필요하고 자기가 고치고 싶은 것을 고칠 수 있게 해라."

**답 (문답으로 정함)**
- **오늘의 MVP는 "조사 도우미"**: 매일 손으로 하던 조사 하나를 AI 에이전트가 웹에서 찾아 표로 정리하고, 한 화면에서 보여 주는 가장 작은 첫 버전. 본보기는 강사님의 스니핏 이야기(손으로 캡처하고 엑셀에 옮기던 일이 5분의 1로).
- **보기 일곱 가지**: 광고 소재 리서치(마케터) / 경쟁사 가격 조사(MD·온라인 영업) / 증정품·프로모션 조사(MD·온라인 영업) / 상세페이지 조사(MD·콘텐츠·CX) / 팝업스토어 리서치(브랜드·공간 마케터) / 교육 프로그램 리서치(교육 회사 운영·기획: 커리큘럼, 강사진, 운영안) / 경쟁 서비스 기능 조사(테크 트랙: 서비스 기획·개발·데이터. 11/15 밤 강사 지시로 더함). 카드의 "이걸로 할게요"를 누르면 조사할 것 칸에 들어갑니다. 보기에 없는 조사를 직접 적어도 됩니다.
- **수업 예시와 강사 시연**: 라라스윗의 경쟁사 가격·프로모션 조사.
- **자료**: 웹에서만 찾습니다. 줄마다 조사일과 출처 링크를 붙이고, 못 찾은 값은 "못 찾음"으로 둡니다(지어내지 않음).
- **오전 기초(다 같이, 프롬프트 6개, 광고 소재는 7개)**: P0 규칙 → W1 채용 공고 → P1 조사 설계서(mvp.md) → P2 첫 조사(research.csv) → (광고 소재면 P2-1 내가 본 광고 붙여 넣기. 11/15 밤 강사 지시로 오전 기본) → P3 보는 화면(mvp.html) → P4 5초 다듬기.

- **랜딩페이지·키비주얼**(공식 일정표 11/16 크리에이티브 트랙 실습)은 오후 B의 마케터 선택지로 남았습니다.
