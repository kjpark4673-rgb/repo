# 팀 발표 뼈대: 신입의 아침 경쟁사 조사를 에이전트로 (5분)

- 쓴 날짜: 2026-11-15 / 발표: 수요일, 5분
- 순서: 문제 - 해결 - 시장 - BM - MVP - 팀 - 요청사항
- 재료: 조원 카드 4장 + 내 pitch_me.md. 카드의 숫자는 적힌 그대로 옮겼어요. 카드에 없는 숫자는 [팀이 정할 곳], 카드에서 비어 있던 칸은 [채울 곳]으로 두었어요.
- 이름 칸이 모두 비어 있어서, 카드를 받은 순서대로 **조원 A, 조원 B, 나, 조원 D**로 불러요. (가정)
  - 조원 A: 경쟁 저당 디저트 몰별 가격·행사 조사
  - 조원 B: 경쟁사 몰별 가격·할인을 같은 양으로 비교
  - 나: 경쟁 몰 자사몰 기능 비교 (pitch_me.md)
  - 조원 D: 경쟁사 광고 소재 조사 (15초 티저 있음)

## 1. 문제

**공통 문제 한 문장:**
> "신입이 매일 아침 손으로 하는 경쟁사 조사 — 가격·행사, 몰 기능, 광고를 사이트마다 열어 보고 엑셀로 옮기느라 하루 40~60분(가정)이 들고, 결과가 흩어져 팀장이 회의 전에 빨리 보기 어렵다."

말할 재료 (카드에서):
- 하루 40~60분 손 조사 (조원 A·D, 가정) / 하루 약 40분 (나, 가정) / 하루 약 40~60분 (조원 B, 가정)
- 용량이 달라 가격 비교가 어려움 (조원 B)
- 결과가 엑셀과 캡처로 흩어짐 (나)
- 결과를 받는 사람: MD 팀장(조원 A·B), 자사몰 기획 팀장(나, 가정), 콘텐츠팀 팀장(조원 D, 가정)

## 2. 해결

**한 줄:** "에이전트가 아침 조사를 대신 모아, 팀장이 열자마자 볼 한 화면으로 만들고, 모든 값에 출처 링크를 단다."

- 4명이 같은 방식으로 각자의 조사를 바꿨다는 것을 보여 주기:
  - 맨 위에 큰 숫자 하나 (가장 싼 값 / 정기구독 1/3 / 광고 7건)
  - 버튼이나 태그로 걸러 보기
  - 출처 링크로 원래 페이지 열기
- 줄인 시간: 4명 모두 **[채울 곳]분** (아직 재지 않음). 목표는 15분 이하(조원 A·D), 10분 이하(나).

## 3. 시장

기준: 회사가 아니라 **"이 조사를 매일 하는 신입과 그 팀"**.

- 누가: 커머스·브랜드 온라인 MD, 가격 담당, 자사몰 기획자, 데이터 분석가, 프로모션·콘텐츠 마케터 (가정)
- 그 팀: 결과를 아침마다 받아 보는 팀장 (MD 팀장, 기획 팀장, 콘텐츠팀 팀장)
- 이런 직무가 나온 채용 공고 예: 컬리·글로우픽·코코지 (조원 A, 가정), 빗썸·쿠팡 (나, 가정, 공고 원문은 못 열고 검색 요약만 봄)
- 이런 사람·팀이 몇 명(몇 곳)인지: **[팀이 정할 곳]**

## 4. BM

- **사내 도구.** 파는 물건이 아니라, 팀이 매일 쓰는 아침 조사 도구.
- 아끼는 시간 = (손으로 걸리던 40~60분(가정) − 에이전트로 걸린 **[채울 곳]분**) × 이 조사를 하는 사람 수 **[팀이 정할 곳]** × 한 달 근무일 **[팀이 정할 곳]**
- 한 사람 기준 하루 **[팀이 정할 곳]분**, 한 달 **[팀이 정할 곳]시간** 아낌
- 덤: 팀장이 회의 전에 한 화면으로 봄 (흩어진 엑셀·캡처 대신)

## 5. MVP (조원마다 한 장, 라이브 데모 한 사람 30초)

각자 45초: 데모 30초 + 테스트 숫자·고친 것 15초.

### 5-1. 조원 A: 경쟁 저당 디저트 가격·행사판
- 조사: 라라스윗 MD가 매일 아침 하던 경쟁 저당 디저트 3곳(마이노멀, 널담, 헤일로탑)의 몰별 가격·행사 조사 → MD 팀장이 받아 봄 (가정)
- 줄인 시간: 손으로 하루 40~60분(가정) → 에이전트로 [채울 곳]분 (재지 않음, 목표 15분 이하)
- 데모 30초:
  1. 화면을 열고 맨 위 "9,220원 · 140g × 3개" 보여 주기
  2. "헤일로탑" 버튼 눌러 "동원몰: 무료배송" 보여 주기
  3. "키토마켓 열기" 눌러 원래 페이지 열기
- 테스트 숫자: 다른 조 학생 2명 중 [채울 곳]명이 과업 3개 중 [채울 곳]개를 혼자 끝냄 (사람 테스트 전)
- 고친 것: 폰에서 출처 링크 칸이 늘 보이게, 링크 글자에 몰 이름 붙이기 (자동 점검으로 찾음)

### 5-2. 조원 B: 같은 양으로 비교하는 가격·할인판
- 조사: 라라스윗 MD가 매일 아침 하는 경쟁사 3곳(헤일로탑·널담·마이노멀) 몰별 가격·할인 조사 → MD 팀장이 받아 봄
- 줄인 시간: 하루 약 40~60분(가정) → [채울 곳]분
- 데모 30초:
  1. 화면 열면 100ml당 가장 싼 곳 큰 숫자
  2. [마이노멀] 눌러 같은 양 비교 값과 할인·쿠폰
  3. [제품 이름 복사]로 출처 찾아가기
- 테스트 숫자: 다른 조 학생 2명 중 2명이 "가장 싼 곳 찾기"를 혼자 끝냄 (20초, 35초)
- 고친 것: 100g당 값을 이름 바로 아래 크게 + 출처 링크에 "(확인 필요)"와 [제품 이름 복사]
- 확인할 것: 데모는 "100ml당", 고친 것은 "100g당"으로 적혀 있어요. 발표 전에 어느 쪽인지 맞추기.

### 5-3. 나: 경쟁 몰 기능 비교판
- 조사: 라라스윗 경쟁 몰 3곳(랭킹닭컴·마이노멀·널담)의 자사몰 기능을 매일 비교 → 자사몰 기획 팀장이 받아 봄 (가정)
- 줄인 시간: 손으로 하루 약 40분(가정) → 에이전트로 [채울 곳]분 (목표 10분 이하)
- 데모 30초:
  1. 큰 숫자 "정기구독 1/3"과 ⚠ 알림
  2. 무료배송 요약 "가장 낮은 곳: 랭킹닭컴 40,000원"
  3. 출처 링크 눌러 새 탭으로 열기
- 테스트 숫자: 다른 조 학생 2명 중 0명이 무료배송 비교를 혼자 끝냄 (정기구독 찾기·출처 열기는 2명 중 2명)
- 고친 것: 무료배송 막대 위에 "가장 낮은 곳" 요약 한 줄, 폰에서는 표 대신 경쟁사별 카드

### 5-4. 조원 D: 경쟁사 광고 소재판
- 조사: 라라스윗 콘텐츠 마케터가 매일 아침 하던 경쟁사 3곳 광고 소재 조사 → 콘텐츠팀 팀장이 받아 봄 (가정)
- 줄인 시간: 손으로 하루 40~60분(가정) → 에이전트로 [채울 곳]분 (목표 15분 이하)
- 데모 30초:
  1. 열자마자 "7건"과 경쟁사 카드 3장
  2. "가격·할인" 태그로 할인 광고 2건 찾기
  3. "출처 열기 (geniet.co.kr)"로 근거 열기
- 테스트 숫자: 다른 조 학생 2명 중 2명이 "출처 확인" 과업을 혼자 끝냄 (할인 찾기는 2명 중 0명)
- 고친 것: 출처 링크에 사이트 이름과 안내를 붙임, 어려운 칸 이름(소구점 등)에 쉬운 풀이를 붙임 (고친 뒤 재테스트 전)

데모 공통 준비: 링크가 발표장에서 안 열릴 때를 위해 화면 캡처를 한 장씩 준비하기.

## 6. 팀

- 4명, 모두 같은 회사(라라스윗) 기준으로 서로 다른 아침 조사를 하나씩 맡음
  - 조원 A: 가격·행사 / 조원 B: 같은 양 가격 비교 / 나: 몰 기능 / 조원 D: 광고 소재
- 이름: [채울 곳] (4명 모두 카드에 비어 있음)
- 한 줄: "한 회사의 아침 경쟁사 조사 네 가지를 한 팀이 나눠 바꿨습니다."

## 7. 요청사항

카드의 재료에서 골랐어요.
1. **실제 MD·마케터·팀장 1명과 15분 사용자 테스트 연결** (4장 모두에 나옴: 조원 A, 조원 B, 나, 조원 D)
2. **경쟁사 사이트 원문을 직접 확인할 수 있는 환경** (나: 지금은 접속이 막혀 검색 요약만 씀)
3. 후보로 더 있음 (시간이 남으면): 광고 한 개 주소 받는 법 조언 (조원 D), 에이전트 시간을 5일 동안 재 볼 시간 (나)
- 테스트할 사람 수·기간: **[팀이 정할 곳]**
