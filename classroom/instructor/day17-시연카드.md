## 전날 10분 · 강사님 맥에서 꼭 확인할 것 (Claude in Chrome)

공식 문서(code.claude.com/docs/en/chrome, support.claude.com 12012173)로 확인한 것은 이렇습니다.
- Pro 요금제에서 쓸 수 있습니다. 브라우저는 Chrome(확장 안내 페이지는 "Chrome only"). 확장과 Claude Code가 **같은 계정**으로 로그인되어야 합니다.
- **터미널(CLI)에서 켜는 법만 문서에 있습니다**: `claude --chrome`으로 시작하거나 대화 중 `/chrome`. 데스크톱 앱 Code 탭에서 켜는 절차는 문서에 없습니다.
- **내 컴퓨터 파일(file://)을 여는 것도 문서에 없습니다.** 문서의 예는 localhost 주소입니다. 가이드 설치 5번에 Chrome의 "파일 URL에 대한 액세스 허용"을 넣었고, P2는 file:// → localhost:8000 → 코드로 점검 순서로 내려가게 했습니다.
- 확인 창(알림 창)이 뜨면 Claude가 멈춥니다. 브라우저 작업은 사용량을 많이 씁니다.

| 확인할 것 | 어떻게 | 결과에 따라 수업에서 |
|---|---|---|
| 데스크톱 앱 Code 탭에서 Chrome이 연결되나 | 확장 설치·로그인 후 Code 탭 입력창에 `/chrome`을 보내 봄. 안 되면 앱 설정에서 Chrome 관련 항목을 찾음 | 되면: 설치 6번을 강사님 화면대로 말함 / 안 되면: 터미널을 쓰는 학생만 `claude --chrome`, 나머지는 P2의 "코드로 점검" 길(수업은 그대로 흐름) |
| P2가 내 화면을 여나 | Day 16 시연 폴더에서 P2를 보냄. Chrome 창이 열리고 mvp.html이 보이는지, 걸린 시간 | file://이 안 되면 localhost로 가는지(python 허락 창). 둘 다 안 되면 학생에게 "코드 점검이 정상"이라고 말함 |
