# Day 16 모의 수업 기록 (2026-11-14 새벽)

> 학생용 자료가 아닙니다. 수강생 실습시트를 읽어 반의 상태를 파악하고, 가상 학생이 가이드를 실제로 따라가게 해서 걸리는 곳을 찾아 고친 기록입니다.
> 이 저장소는 공개 상태라 학생 이름과 학생별 내용은 적지 않았습니다. 유형과 숫자만 적습니다.

## 1. 시트에서 본 반의 모습

28명 가운데 24명의 실습시트를 읽었습니다. 3명의 시트는 강사 계정으로 열리지 않았고, 테크 트랙 1명은 시트가 목록에 없습니다.

| 본 것 | 숫자 | 월요일에 뜻하는 것 |
|---|---|---|
| 금요일(11/13) 기록을 남긴 학생 | 3명 | 거의 모두가 벤치마킹 없이 시작한다. 1교시의 P1이 꼭 필요하다 |
| 목요일(11/12) 기록을 남긴 학생 | 9명 안팎 | 퍼소나 파일이 폴더에 없는 학생이 많다. 프롬프트가 "없으면 없는 대로" 돌아가야 한다 |
| 자기 브랜드로 작업하는 학생 | 절반 이상 | 11/11 공지 탭에 학생별 브랜드가 있다. 업종은 뷰티가 가장 많고 식품, 육아, 병원, 은행, 캐릭터, 영화, 아웃도어, 오프라인 매장이 있다. "내 회사로"가 예외가 아니라 본선이다 |
| 열 수 없는 링크(내 컴퓨터 경로, localhost)를 적은 학생 | 6명 안팎 | 마무리에서 "링크를 어떻게 만들어요?"가 가장 많이 나올 질문이다 |
| 기록이 2주 가까이 끊긴 학생 | 7명 안팎 | 능력이 아니라 기록 습관일 수 있다. 월요일 초반에 조장이 먼저 살핀다 |
| 배포, 게임, 스킬 만들기를 스스로 해 본 학생 | 5~6명 | 본선을 30분 안에 끝낸다. 교시마다 "먼저 끝났다면"이 있어야 한다 |
| 테크 트랙 | 6~8명 | 저장소와 배포 경험이 뚜렷한 학생과 기록이 거의 없는 학생으로 갈린다 |

만족도 설문(11/2까지 65건)에서 나온 말: 난이도는 "적당하거나 쉽다"가 다수였습니다. 불만은 테크 쪽에서 수업이 마케팅으로 쏠린다는 것, 안내된 커리큘럼과 다르게 운영된다는 것, 오후 실습이 길다는 것이었습니다. 요청은 전체 로드맵, 추천 스킬, 프롬프트를 받는 것을 넘어서는 방법이었습니다.

## 2. 모의 수업을 어떻게 했나

| 가상 학생 | 설정 | 결과 |

## 3. 모의 수업과 검토에서 걸려 고친 것

| 걸린 것 | 고친 것 |
|---|---|
| 테크 트랙의 계획이 "보고는 3줄" 규칙에 막혀 화면에 안 나옴 | P0 규칙에 "내용을 보여 달라고 하면 그대로 보여 준다"를 넣고, T2에 "계획 전체를 그대로 보여줘"를 적음 |
| 키비주얼 프롬프트가 영어로 3,700자 | "한국어로 3문장 안", "프롬프트 4개만 보여줘"로 바꿈. 다시 돌린 결과 950자 안팎 |
| 광고 규정 점검 답이 2,000자 | "가장 위험한 5개만 표로"로 바꿈. 다시 돌린 결과 700자 |
| "파일 내용 보기"가 HTML 코드를 통째로 보여 줌 | 글 파일은 그대로, HTML은 화면에 무엇이 있는지로 바꿈 |
| 프롬프트 안의 "(여기에 적어요)" 괄호를 어떻게 고치는지 알 수 없음 | 괄호를 없애고 페이지의 입력 칸으로 옮김. 적으면 프롬프트의 파란 글자가 바뀌고, 안 적으면 "없음"으로 나감 |
| 결과가 전부 .md 파일에 있는데 여는 법이 없음 | 준비 구간에 "프롬프트 쓰는 법"과 리모컨 "파일 내용 보기"를 넣음 |
| 강의는 "여섯 칸"인데 프롬프트는 일곱 가지, "빈 땅"은 프롬프트에 없는 말 | 강의 목록을 프롬프트와 같은 순서, 같은 말로 맞춤 |
| "화면"이 다섯 가지 뜻으로 쓰임 | 랜딩페이지의 여덟 부분은 "칸", 맨 위 칸은 "첫 화면"으로 통일 |
| "기획전", 랜딩페이지와 상세페이지의 차이, (가정)과 [채울 곳]의 차이가 설명 없이 나옴 | "오늘 처음 나오는 말" 카드를 넣음 |
| 테크 트랙이 3교시에 계획 없이 바로 만들고, 4교시에 할 일이 없음 | T2(계획), T3(만들기), T4(다듬기), T5(샘플 데이터)로 다시 나누고, 맨 위에 테크 트랙의 길을 적음 |
| 3교시에 일이 몰리고 4교시는 비어 있음. 프롬프트가 얼마나 걸리는지 없음 | 첫 화면 다듬기(P7)를 4교시로 옮기고, "30초에서 1분, P1은 1~2분"을 적음 |
| 무엇이 꼭이고 무엇이 선택인지 알 수 없음 | 꼭 하는 프롬프트 제목에 (꼭)을 붙임 |
| 허락 창 설명이 맨 아래 접힌 칸에 있음 | 준비 구간으로 올림 |
| 병원, 은행, 영화처럼 물건을 팔지 않는 브랜드는 "지금 사기"가 안 맞음 | 마지막 칸을 "예약, 신청, 방문"으로 읽게 프롬프트와 강의에 적음 |
| 키비주얼이 "가로로 긴 이미지"라 폰 첫 화면과 안 맞고, 인스타그램용 그림이 랜딩페이지에도 들어감 | 키비주얼은 첫 화면의 장면을 세로로, 인스타그램 시안은 sns.html에만 넣게 바꿈 |
| P4가 "고르기"인데 후보를 학생이 못 봄 | 후보 5개와 Claude가 고른 것을 보여 주고, 학생이 바꿀 수 있게 함 |
| 금요일 가이드에 걸어 둔 "월요일 가이드 열기" 링크가 수강생에게 안 열림 | 링크를 지우고 "월요일 수업을 시작할 때 드려요"로 바꿈 |
| 금요일 탓이 학생에게 가는 것처럼 읽힘 | "금요일 가이드의 프롬프트", "여러분이 잘못한 게 아니에요"로 주인을 적음 |

## 5. 수업 전에 강사가 확인할 것

1. Day 16 가이드의 공유 설정. 비공개 상태입니다.
2. "화면을 링크로 만들기" 한 줄이 학생 화면에서 되는지. 공식 문서로는 Pro에서 되지만 앱 버전 조건이 있고, 학생 화면에서 돌려 보지 못했습니다. 안 되면 마무리의 링크 안내를 말로 바꿔 주세요.
3. 시트가 열리지 않는 3명과 시트가 없는 1명. 기록을 볼 수 없어 모의 수업에 넣지 못했습니다.
4. 기록이 끊긴 7명 안팎은 조장이 1교시에 먼저 살피게 해 주세요.
5. 병원, 은행처럼 광고 규정이 엄격한 업종의 학생에게는 4교시에 "광고 규정 점검"을 직접 권해 주세요. 점검 결과는 Claude가 아는 일반 원칙이고, 법률 확인은 아닙니다.
