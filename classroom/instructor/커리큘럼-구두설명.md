## 피칭 데이가 왜 있나

1. **구간의 결승선.** Lifestyle 2주 동안 고객여정, BM, 경쟁 분석, 숫자, MVP를 따로따로 만들었습니다. 피칭 데이는 이 조각을 하나의 제안으로 묶는 날입니다. 묶지 않으면 조각으로 흩어집니다.
2. **발표는 다섯 번, 뒤로 갈수록 본 경기.** 11/9(완료) → 11/18 피칭 데이 → 12/4 개인 데모데이 → 12/18 프로젝트 최종 발표 → 12/23 해커톤 심사(CJ 현업이 심사). 11월의 발표는 모의고사이고 12월이 본시험입니다. 모의고사를 건너뛴 사람은 본시험에서 처음 맞습니다.
3. **면접과 같은 형식.** 피칭은 "문제 → 해결 → 시장 → BM → MVP → 팀 → 요청" 순서로 5분 안에 말하고 질문 3분을 받습니다. 면접에서 포트폴리오를 설명하는 순서와 같습니다.
4. **링크로 발표합니다.** PPT가 아니라 브라우저에서 열리는 HTML 발표를 링크로 배포합니다. "남이 열 수 있는 링크"를 처음 공식으로 내는 날입니다.

형식(공식 설계안): 조별 HTML 인터랙티브 피치덱을 링크로 배포, 5분 피치 + 라이브 데모 + 3분 Q&A, 발표 피드백 시트 작성.
