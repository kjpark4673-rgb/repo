# Day 18 프롬프트 시험 결과 (1판, 2026-11-15)

## 1판: 인터랙티브 HTML 발표(피칭 데이, 11/18) — 가장 최신

공식 11/18 줄(인터랙티브 HTML 피치덱, 문제-해결-시장-BM-MVP-팀-요청사항, 5분 피치 + 라이브 데모 + 3분 Q&A, 발표 피드백 시트, Vercel 배포)과 강사님 답(조 번호 순서, 피드백은 강사님과 다른 조 동료, 링크는 아티팩트와 Vercel 두 방법 준비, 3인 1조)으로 짰습니다. 흐름은 내 장 HTML(P2) → 조 발표 페이지 합치기(P3) → 링크와 대본(P4) → 메뉴 A~D(P5~P8) → 발표 뒤 피드백 정리(P9) → W2입니다.

- **시험 설정:** 팀 한 개는 3인 1조(나 + 조원 A, C). 카드는 조원 두 명분만 줬습니다. 개인 학생 세 명(A, C, E)과 혼자 만든 학생(S), 조원 파일이 빠진 조(Z)도 돌렸습니다.
- **고친 것 (시험 중):**
  - P0이 기존 규칙을 통째로 바꿔 Day 16~17 규칙(출처, CSV BOM, 가상 회사)이 빠졌습니다. → 기존 규칙은 두고 발표 규칙만 더하게 바꿨습니다. 고친 뒤 확인: 수업 작업 규칙과 사용자 테스트 규칙이 남고 발표 규칙이 더해졌습니다.
  - 시험 설정 실수로 팀이 네 명이 되었습니다. → 3인 1조로 다시 맞췄습니다.
  - P1이 이미 있던 team_pitch.md의 옛 카드와 옛 이름을 가져와 없는 조원("조원 B")을 만들었습니다. → P1은 카드와 pitch_me.md 기준으로 처음부터 다시 쓰게 하고, 빈 자리는 [조원 카드 없음]으로 두게 했습니다. 고친 뒤 확인: 카드 2장 + 나 = 3명으로 맞았습니다.
  - 나를 "[조원 B]"로 적었습니다. → "나"로 적게 했습니다. 고친 뒤 P1만 다시 확인했습니다.
- **깨끗한 팀 폴더 전체 흐름(P0~W2):** 옛 파일 없이 처음부터 돌렸습니다. 팀 발표 페이지 team_deck.html이 생겼고, 나·조원 A·조원 C 장이 들어갔습니다. 발표 파일 네 개는 브라우저에서 오류 없이 열렸고, 버튼이 눌리고 넘기기가 됩니다.
- **발행 제한:** 시험 환경에서는 아티팩트 발행이 승인되지 않아 링크가 만들어지지 않았습니다. 대본은 "발표 파일 이름으로 발표한다"고 적었고, 발표 링크는 학생 화면에서 확인해야 합니다. Vercel 대안은 시험하지 않았습니다.
- **P4 예상 질문:** 시장 크기는 숫자가 없어 "확인해서 알려 드릴게요"로 답했습니다. 못 찾은 칸이 많다는 질문에는 실제 비율(42칸 중 18칸)로 답했습니다. 이것은 Day 16 시험 결과에서 나온 값입니다.

### 시험 중 걸린 것과 고친 곳 요약

| 걸린 것 | 고친 곳 |
|---|---|
| P0이 기존 규칙을 덮어씀 | P0을 "기존 규칙은 두고 발표 규칙만 추가"로 |
| P1이 옛 파일의 카드와 이름을 가져옴 | P1을 카드와 나 기준으로 처음부터 다시 쓰기 |
| 나를 "[조원 B]"로 적음 | P1이 나를 "나"로 적기 |
| 3인 1조 안내가 없음 | MVP 칸에 "3인 1조면 장이 세 장(나 포함)" |
