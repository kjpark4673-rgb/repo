### 잘 된 것 (확인한 것)

- 사람 테스트 칸을 비우면 P3이 맨 위에 "사람 테스트 기록 없음"을 적고 자동 점검만으로 씀. 사람의 말을 지어내지 않음(콘텐츠 마케터, 붙여 넣기만 한 학생).
- P0이 어제 CLAUDE.md의 "나와 회사"를 지우지 않음(입력 칸이 비어도 MD, 닥터지가 남음). 빈 폴더에서는 Day 16 파일을 먼저 만듦(1분 46초).
- 백업 이름이 mvp_backup_시각으로 나와 Day 16의 mvp_v1.html과 부딪히지 않음(자기 브랜드 갈래에 mvp_v1.html이 있었음).
- P4가 학생이 적은 고칠 순서("2번 먼저, 3번은 빼기")를 따름. W2가 그 이유("두 사람 모두")가 기록(한 사람)과 다르다고 짚어 [내가 적을 곳]으로 남김.
- P7에 두 번째 테스트를 비우면 화면을 고치지 않고 다음에 볼 것만 알려 줌.
- W2는 붙여 넣기만 한 학생에게 "내가 내린 결정"을 비우고 면접 문장 2, 3을 [내가 적을 곳]으로 남김.

### 이 환경에서 생긴 일 (가이드 문제가 아님)

- Chrome 확장이 없어 P2는 모두 "Chrome 없이 코드로 점검"으로 끝남. 로컬 서버(python)와 브라우저 열기는 셸 명령이 막혀 시도만 함. **Chrome 길은 시험하지 못함 → 시연카드의 전날 확인표.**
- 출처 사이트가 막혀 "출처 링크 3개 열기"는 확인하지 못했다고 적힘.
- 자기 브랜드 갈래의 P2가 auto_check.md를 작업 폴더가 아닌 비슷한 이름의 다른 경로에 저장함(경로가 긴 시험 폴더에서 전에도 있던 일). P3은 그대로 진행.
- 복사(mvp_1116.html)는 셸 대신 읽고 쓰기로 함. 학생 화면에서는 cp/copy 허락 창이 뜰 수 있음(가이드 허락 창 안내에 넣음).

### 이 시험이 보장하지 않는 것

- Claude in Chrome이 실제로 화면을 눌러 보는 길, 데스크톱 앱에서 연결하는 법(공식 문서에 없음).
- 영상 AI(Google Flow, Kling)로 실제 영상을 만드는 일, 무료 크레딧의 한국 적용.
- 아티팩트 발행(링크 만들기) 상자. 시험기에서는 발행 도구를 쓰지 않음.
- 사람 테스트를 실제 사람이 할 때 걸리는 시간.
