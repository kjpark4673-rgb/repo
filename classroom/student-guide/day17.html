어제 폴더를 열고, Claude in Chrome을 설치해요

왜 해요? 오늘은 어제 파일을 이어서 써요. Chrome은 2교시에 Claude가 화면을 직접 눌러 볼 때 써요.

어제 적은 내 일과 회사

어제 P0을 보낸 폴더라면 비워 둬도 돼요. Claude가 폴더의 CLAUDE.md에 적힌 것을 그대로 써요. 오늘 새 폴더에서 시작했거나 회사를 바꿨다면 적어요. 회사를 바꾸면 제품과 고객 칸도 꼭 바꿔요.

허락 창이 뜨면

방금 보낸 프롬프트가 시킨 일이면 Yes를 눌러요. 오늘 자주 뜨는 것: 파일 만들기와 고치기, 파일 복사(cp, copy), 웹 검색, 로컬 서버 켜기(python), 브라우저 열기(open, start), Chrome 조작, 링크 만들기(아티팩트 발행).

파일이나 폴더를 통째로 지우겠다고 하거나(rm, delete), 시키지 않은 일을 하겠다고 하면 누르지 말고 강사를 불러요.

Claude in Chrome 설치 · 다 같이 15분

강사님 화면을 보며 같이 해요. 결제나 회원 가입처럼 돈과 개인정보가 오가는 일은 Claude in Chrome이 하지 않게 되어 있어요.

  1. Chrome 브라우저를 열어요. 없으면 먼저 설치해요. Edge, 웨일 같은 다른 브라우저 말고 Chrome으로 해요.
  2. Chrome 웹 스토어에서 Claude를 찾아요. 만든 곳이 Anthropic인지 확인하고 Chrome에 추가를 눌러요. 강사님이 링크를 주면 그 링크로 가요.
  3. 오른쪽 위 퍼즐 모양 아이콘을 누르고 Claude 옆 압정을 눌러 고정해요.
  4. Claude 아이콘을 눌러 Claude Code와 같은 계정으로 로그인해요. 권한을 묻는 창이 뜨면 허용해요. Claude가 화면을 읽고, 누르고, 입력하는 데 필요한 권한이에요.
  5. 주소창에 chrome://extensions를 쳐요. Claude의 세부정보를 누르고 파일 URL에 대한 액세스 허용을 켜요. 내 폴더의 mvp.html을 Chrome이 열 수 있게 하는 거예요.
  6. Claude Code와 연결해요. 강사님 화면을 따라 해요. 터미널에서 Claude Code를 쓰는 사람은 claude --chrome으로 시작하거나, 대화 중에 /chrome을 보내 연결 상태를 봐요. 연결됐는지 모르겠으면 그냥 2교시에 P2를 보내요. 안 되어 있으면 P2가 알아서 코드로 점검해요.

연결이 안 되어도 수업은 그대로 가요. 2교시 P2가 Chrome 없이 코드를 읽어서 같은 점검을 해요. 설치는 쉬는 시간에 강사님과 마저 해요.

짧은 강의

사용자 테스트가 뭐예요?

만든 것을 진짜 쓸 사람에게 시켜 보고, 설명하지 않고 지켜보며 어디서 막히는지 찾는 일이에요.

비유: 어제 시식 코너(MVP(Minimum Viable Product))를 차렸다면, 오늘은 손님이 맛보는 얼굴을 지켜보는 날이에요. "맛있죠?"라고 묻지 않고, 어디서 멈칫하는지 봐요.

사용자 테스트예요

  • 할 일 한 문장(과업)을 주고 혼자 해 보게 하기
  • 걸린 시간과 멈칫한 곳을 적기
  • 한 말을 그대로 적기

사용자 테스트가 아니에요

  • "어때요? 괜찮죠?"라고 의견만 묻기
  • 내가 옆에서 설명하며 눌러 주기
  • 만든 사람끼리 보고 "좋네"로 끝내기

하는 순서: 과업 정하기 → 시켜 보기(설명하지 않기) → 본 것 적기 → 여러 사람이 막힌 곳부터 고치기 → 다시 시켜 보기

직무마다 이렇게 해요

회사마다, 직무마다 사용자 테스트를 해요. 오늘 배우는 순서가 그대로 쓰여요.
