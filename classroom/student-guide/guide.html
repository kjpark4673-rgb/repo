숫자는 지어내지 않아요

AI는 그럴듯한 숫자와 후기를 지어내요. 모르는 값은 [실데이터 입력]으로 남기고, 공식몰·후기에서 직접 채워요.

용어

어려운 말, 비유로 쉽게

스킬 = 레시피 카드

AI가 일하는 방법을 적은 파일(SKILL.md)이에요. 한 번 써 두면 매번 설명하지 않아도 돼요.

프롬프트 = 주문

식당에서 하는 주문 한 번이에요. 대화가 끝나면 사라져요. 스킬은 파일로 남아요.

퍼소나 = 단골손님 일기장

"25~34세 여성"이 아니라 "밤 10시 냉동실 앞에서 10분째 서성이는 29살"처럼 장면이 보여야 해요.

5-Whys = 양파 껍질 벗기기

"왜?"를 반복해서 속마음까지 가요. 마지막 답이 감정이면 성공이에요. 꼭 5번일 필요는 없어요.

고객여정지도 = 지하철 노선도

손님이 1호역에서 타서 6호역(재구매)까지 가요. 중간에 내리는 게 이탈이에요.

훅 카피 = 낚싯바늘 미끼

역마다 손님이 내리는 이유가 달라요. 그 이유에 직접 답하는 문장이 좋은 훅이에요.

출력 스위치 = 요리법 선택

같은 재료(퍼소나+여정)로 릴스, 팝업, 여행 상품을 만들어요.

HTML = 웹용 PPT 파일

더블클릭하면 크롬으로 열려요. 코드를 몰라도 돼요.

얕은 5-Whys vs 깊은 5-Whys

얕아요 · 같은 말 반복

  • 왜? 단 게 먹고 싶어서
  • 왜? 디저트를 좋아해서
  • 왜? 맛있어서
  • 왜? 달아서
  • 왜? 단 걸 좋아해서

깊어요 · 한 칸씩 내려가요

  • 하루 종일 참아서
  • 단 게 유일한 보상이라서
  • 퇴근 후 쓸 에너지가 없어서
  • 저당은 맛없다는 실패 경험
  • 즐거움도 관리도 지키고 싶어서

같은 단어가 반복되면 얕은 거예요. 행동 → 상황 → 제약 → 과거 경험 → 바라는 자기 모습 순서로 내려가요.

짝꿍과 표를 바꿔 보고 5가지 체크

빈칸은 내가 직접 채워요

이런 곳에서 채워요

  • 브랜드 공식몰 제품 상세
  • 판매처 구매 후기
  • 인스타 해시태그 실제 게시물
  • 네이버 데이터랩 검색 추이

3곳 이상 채우고, 칸 옆에 출처를 적어요. 후기는 작성자 아이디를 지우고 출처만 남겨요.

CJM 단계모드 A 릴스모드 B 팝업모드 C 여행

3 의심비교 컷시식·체험존예약 망설임 해소

관찰 숙제. 세 결과물을 나란히 놓고 같은 것 한 줄, 다른 것 한 줄을 적어 보세요.

모드 A15초 릴스

0~3초멈추게 하기냉동실 앞 한숨 (1단계)
3~8초의심 꺼내기"저당은 맛없잖아" (3단계)
8~12초깨뜨리기첫 숟갈 + 근거 자막 (4단계)
12~15초행동 부르기저장·댓글 (6단계)

첫 3초에 제품이 나오면 광고처럼 보여 넘겨요. 제품보다 짜증 나는 순간이 먼저예요.

모드 B성수 팝업

입구 · 1단계

포토존

"밤 10시의 냉동실" 세트로 멈추게

가운데 · 3단계

시식·비교존

블라인드 시식으로 의심 깨기

출구 · 4·6단계

구매·인증존

현장 구매, 스토리 인증 혜택

냉동 디저트는 보관·녹는 시간이 운영 문제예요. 냉동고 위치와 시식 회전 계획도 확인해요.

모드 C여행·웰니스

손님이 바뀌면 일기장(퍼소나)부터 다시 써요. 모드 A·B는 같은 손님, 모드 C는 다른 손님이에요.

  • "가서 실망하면 주말 날림"
  • "혼자 가도 어색하지 않나"
  • "사진이랑 실제가 다르면?"

예시예요. 내 결과와 달라도 괜찮아요.
